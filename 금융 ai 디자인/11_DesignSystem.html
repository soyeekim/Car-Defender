9-0. 대화와 첨부 카드
팝업 위에 팝업이 뜰 때 — 뒤 창을 흰색으로 덮지 말고 뒷막을 한 겹 더 얹는다. 값은 같은 토큰 rgba(15,18,24,0.55). 흰 덮개(rgba(255,255,255,0.6))는 1차 버튼을 정의에 없는 연보라로 바꿔 놓으므로 쓰지 않는다.
두 번째 팝업은 뒤 창이 아니라 화면 전체를 기준으로 가운데에 놓는다 — position:absolute; inset:0; display:flex; align-items:center; justify-content:center. (H35 발송 확인 · H36 발송 실패)
팝업 폭 계단 — 400(경고·확인) · 480(목록이 있는 확인) · 560(도표·절차) · 640(입력 창) · 760(문서 창). 그 밖의 값 금지.
대화는 추가만, 삭제 없음. 화면이 넘어가도 앞 메시지는 그대로 쌓여 있고 새 메시지가 아래에 붙는다. 시안이 한 장에 한 상태만 보여 준다고 해서 앞 대화가 사라지는 것이 아니다.
사실이 확정되는 순간 같은 항목이 현황판 칩으로 나타나고 분자가 커진다. 분모는 F2의 필수 6가지로 고정이며, 영상을 올리기 전에는 분모를 보여 주지 않는다.
자동으로 도는 작업(업로드·분석·재판정)에는 반드시 멈추는 길이 있어야 한다 — 업로드 [취소] · 분석 [분석 멈추기] · 재판정 [이전 판정으로 되돌리기].

9. 상태 — 누를 때 · 초점 · 잠금
마크업의 scp0~scp5 클래스가 곧 "누를 수 있는 것"이다. 마스터 파일 <head>의 #interaction-states 스타일에 아래 값이 실제로 들어 있으니 그대로 옮기면 된다.
scp1 주 버튼 — 기본 #4D33DF / 호버 #3D28B8 / 눌림 #3D28B8 + inset 0 2px 4px rgba(0,0,0,.18)
scp0 보조·팝업 버튼·칩 — 호버 배경 #F6F7F9 + 테두리 #CFC7F7 / 눌림 배경 #EEEBFC
scp3 아이콘 버튼·텍스트 링크 — 호버 배경 #F0F2F5 + r8 · 최소 높이 32(PC 마우스 기준)
scp4 근거 목록 행 / scp5 사이드바 사건 행·현황판 행 — 호버 배경 #F6F7F9 · scp5 최소 높이 44
초점(공통) — outline 2px solid #4D33DF · outline-offset 2px · r12. 입력칸만 예외로 테두리 1.5px #4D33DF + 링 0 0 0 3px #EEEBFC 를 쓴다. 초점은 모든 누를 수 있는 것에 보여야 한다 — 키보드로 쓰는 사람이 지금 어디에 있는지 알 수 있어야 한다.
잠금 — 배경 #F0F2F5 · 글자 #98A2B3 · 테두리 없음 · 커서 not-allowed. opacity 로 흐리게 만들지 마라 — 정의에 없는 연보라가 생긴다.
움직임 — 배경·테두리 색만 120ms. "움직임 줄이기" 설정이면 끈다.
누르는 영역 최소 크기 — 모바일 44×44(예외 없음) · PC 32×32(마우스 기준, WCAG 24 이상). 보이는 아이콘 크기는 그대로 두고 감싼 상자만 키운다.
10. 화면 폭과 스크롤
화면 폭
PC(데스크탑·랩탑) 1024~1920 — 이 범위를 다 받는다. 시안은 1440 기준으로 그렸다. 사이드바 260과 현황판 340은 flex:0 0으로 고정이고 채팅 열만 늘고 줄어든다. 판정 카드와 말풍선은 max-width:560px; min-width:0 — 고정 width 금지.
1920~1280 — 3열 그대로. 채팅 열이 넓어져도 카드는 560에서 멈추고 열 안에서 왼쪽 정렬을 지킨다.

스크롤 — 세 곳이 스크롤한다. 마스터에 클래스로 들어 있다.
.chat-scroll 채팅 목록 · .panel-scroll 현황판·모바일 현황 시트 · .doc-scroll 서류 전문 본문 — 전부 min-height:0; overflow-y:auto.
min-height:0 을 빼면 안 된다. flex 자식이 줄어들지 못해 입력 바가 화면 밖으로 밀려난다. 판정 화면은 내용이 900px에 꼭 맞아 여유가 0px이라 문장 한 줄만 길어져도 바로 깨진다.
스크롤 상자는 자식의 그림자를 직선으로 자른다. 좌우 여백을 24px 이상 두어 카드 그림자가 살아 있게 한다.
