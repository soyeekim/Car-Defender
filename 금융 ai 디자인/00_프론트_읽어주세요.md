## 3. 파일 안에 **이미 들어 있는** 규칙 — 새로 만들지 마세요

### 3-1. 누를 때·초점·잠금 (`<head>` 의 `#interaction-states`)
마크업의 `scp0`~`scp5` 클래스가 곧 "누를 수 있는 것"입니다. 값은 이미 CSS로 들어 있습니다.

| 클래스 | 무엇 | 상태 |
|---|---|---|
| `scp1` | 주 버튼 | 호버 `#3D28B8` · 눌림 `#3D28B8` + `inset 0 2px 4px rgba(0,0,0,.18)` |
| `scp0` | 보조·팝업 버튼·칩 | 호버 `#F6F7F9` + 테두리 `#CFC7F7` · 눌림 `#EEEBFC` |
| `scp3` | 아이콘 버튼·텍스트 링크 | 호버 `#F0F2F5` + r8 · 최소 높이 32 |
| `scp4` | 근거 목록 행 | 호버 `#F6F7F9` |
| `scp5` | 사이드바 사건 행·현황판 행 | 호버 `#F6F7F9` · **최소 높이 44** |

- **초점(공통)** `outline: 2px solid #4D33DF; outline-offset: 2px`. 입력칸만 예외로 테두리 `1.5px #4D33DF` + 링 `0 0 0 3px #EEEBFC`.
- **잠금** 배경 `#F0F2F5` + 글자 `#98A2B3`. **`opacity`로 흐리게 만들지 마세요** — 정의에 없는 연보라가 생깁니다.
- 클래스 이름은 버리고, 그 자리에 실제 `<button>` `<a>`를 쓰세요.

### 3-2. 스크롤
`.chat-scroll`(채팅 24곳) · `.panel-scroll`(현황판·모바일 시트 25곳) · `.doc-scroll`(서류 전문) — 전부 `min-height: 0; overflow-y: auto`.
- **`min-height: 0`을 빼면 안 됩니다.** flex 자식이 줄어들지 못해 입력 바가 화면 밖으로 밀려납니다.
- 판정 화면은 내용이 900px에 꼭 맞아 **여유가 0px**입니다. 문장 한 줄만 길어져도 바로 스크롤이 걸립니다.
- 스크롤 상자는 자식 그림자를 직선으로 자릅니다. 좌우 여백 24px 이상을 유지하세요.

### 3-3. 화면 폭
- **PC(데스크탑·랩탑) 1024~1920** — 이 범위를 다 받습니다. 시안은 1440 기준으로 그렸습니다.
- **1920~1280** — 마크업으로 구현돼 있습니다. 사이드바 `flex: 0 0 260px`, 현황판 `flex: 0 0 340px`, 채팅 열만 늘고 줄어듭니다. 판정 카드·말풍선은 `max-width: 560px; min-width: 0`.
- **1280~1024** — 현황판을 오른쪽 서랍으로 접고 머리글에 [현황] 버튼. 사이드바 260은 유지. 1024에서 채팅 열은 764px 남습니다.
- **태블릿 768~1023** — 사이드바와 현황판을 **둘 다 서랍으로** 접고 채팅 한 열만 남깁니다. 머리글 왼쪽 [사건], 오른쪽 [현황]. 카드·말풍선은 `max-width: 560px` 유지하고 열 가운데 정렬.
- **모바일 768 미만** — 한 열(375 기준).
- 1280·1024 경계와 모바일 경계의 **확인용 시안은 없습니다.** 규칙은 `11_DesignSystem.html` 10절에 값으로 있으니, 만들기 전에 디자인 담당(현)과 한 번 맞춰 주세요.

### 3-4. 간격·터치
- 간격(gap·padding·margin)은 **4의 배수만**. 예외 없음. 6px 색점 · 비율 막대 h8/h10 · 1px 선은 간격이 아니라 부품 규격이라 예외입니다.
- 누르는 영역 최소 크기 — **모바일 44×44(예외 없음) · PC 32×32**. 보이는 아이콘 크기는 그대로 두고 감싼 상자만 키웁니다.

### 3-5. 마크업
- 전부 `<div>`입니다. `<button>` `<input>` `<a>`가 없고 `aria-*` `role` `alt`도 없습니다. 구현하며 넣어 주세요.
- 아이콘은 전부 **인라인 SVG**라 별도 자산이 필요 없습니다. 20×20 그리드 · 선 굵기 1.5px · 색 `currentColor`.
- `m05`·`m06`의 진행 띠에는 `data-step` / `data-steps` / `aria-label`이 들어 있습니다. 나머지 모바일 화면에도 같은 규칙으로 넣어 주세요.

## 6. 기술 메모

- **글꼴**: Pretendard 하나. 지금 파일은 jsdelivr **CDN**에서 불러옵니다.
  → 심사 기간(9/7~9/11) 내내 열려 있어야 하므로 **폰트 파일을 프로젝트에 넣어 주세요.** CDN이 막히면 글꼴이 통째로 바뀝니다.
- **숫자**: 비율·시각·용량은 `font-variant-numeric: tabular-nums`.
- **한글 줄바꿈**: `word-break: keep-all` — `10_디자인.html`에는 일부에만 걸려 있으니 **전역으로 넣어 주세요.**
- **다크 모드**: 이번엔 만들지 않습니다.
- **움직임**: 카드 등장 150ms 아래→위 8px, 분석 중 점 깜빡임. 그 외 없음. "움직임 줄이기" 설정이면 모두 끕니다.

- **자동으로 도는 작업**(업로드·분석·재판정)에는 반드시 멈추는 길이 있습니다 — [취소] · [분석 멈추기] · [이전 판정으로 되돌리기].
