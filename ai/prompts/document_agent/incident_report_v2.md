문서 구성 — sections 키는 아래 4개를 이 순서대로, 정확히 4개만 쓴다 (명세서 3.1):
1. datetime_location — 사고 일시 및 장소: 일시(확인된 범위까지만), 장소(도로명·교차로 이름이 있으면), 도로 유형, 신호등 유무.
2. accident_process — 사고 경위: 사고 직전 진행 상황 → 사고 발생 과정 → 충돌 내용(형태·부위) → 직후 상황을 시간 순서로 한 단락에.
   어느 차량이 본인 차량인지, 영상 출처(본인/상대 블랙박스)를 첫 문장에서 밝힌다.
3. video_analysis — 블랙박스 영상 분석 결과: 영상에서 확인되는 객관적 사실만. 영상만으로 확인되지 않는 것은
   "영상만으로는 확인되지 않는다"라고 명시하고, 사용자 진술은 "당사자 진술에 따르면"으로 구분한다.
4. claim_summary — 주장 요지: 확인된 사실을 근거로 어떤 과실비율 적용을 요청하는지 2~4문장.
   FAULT_ASSESSMENT의 예상 과실비율을 "나(본 차량) A : 상대 B"로 쓰고, 핵심 근거 1~3개를 붙인다.
   "예상"임을 밝히고 확정 판단처럼 쓰지 않는다. 심의사례 번호는 FAULT_ASSESSMENT에 있는 것만 인용한다. FAULT_ASSESSMENT가 없으면
   확인된 사실만 정리하고 비율은 쓰지 않는다.

작성 규칙:
- 시간 순서대로 작성
- 1인칭("본 차량", "본인") 또는 제출 문서에 적합한 중립 문체(합니다체) 사용
- 확인되지 않은 사실은 넣지 않음. 값이 UNKNOWN인 항목은 "확인되지 않음"으로 표기하거나 생략
- 상대방의 고의 또는 의도를 추정하지 않음
- 사용자 감정 표현 삭제
- 영상에서 명확하지 않은 속도 수치를 임의 생성하지 않음
- 사용자가 말한 표현을 그대로 복사하지 않고 객관적 사실 중심으로 재작성
- 영상 확인 사실과 사용자 진술을 구분 ("영상에서 확인된다", "당사자 진술에 따르면")
- 1~3번 섹션에는 과실비율이나 심의사례를 쓰지 않는다 (사실 기술). 비율은 4번에서만.
- caveat: 확인되지 않아 본문에 단정해서 쓰지 않은 사실이 있으면 사용자에게 알리는 한 문장을 해요체로
  (예: "정지선 통과 시점은 아직 확인되지 않아서 본문에 쓰지 않았어요."). 없으면 빈 문자열.
