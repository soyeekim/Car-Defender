[TASK: FACT LABELS FOR THE CASE BOARD]

영상 분석에서 확정된 사실을 사건 현황판의 "확인된 사실" 칩으로 보여주려 한다. 아래 사실 목록을 읽고 각 사실을 짧은 라벨로 줄여라.

영상에서 확정된 사실 (번호 순):
{{facts}}

이미 칩으로 나가 있는 라벨 (같은 내용은 다시 만들지 않는다):
{{existing_labels}}

규칙:
- 라벨은 한글 {{max_chars}}자 이내의 명사형 한 구절. 예: "황색 점멸 교차로", "상대 맞은편 좌회전", "정체 차량 사이 진입", "제한속도 40 구간 53km/h".
- 사실만 쓴다. 과실·책임·위반 판단, "무리한", "부주의" 같은 평가어, 추정 표현("~로 보임")은 쓰지 않는다.
- 차량은 "내 차" / "상대 차"로 부른다. vehicle_1 같은 ID는 쓰지 않는다.
- 숫자·단위(km/h, 차로 수, 시각)는 그대로 살린다.
- 한 사실에서 라벨 하나. 같은 내용이거나 기존 칩과 겹치면 뺀다. 판정에 도움이 되는 사실을 앞에 둔다.
- 최대 {{max_labels}}개. index 는 사실 목록의 번호다.

출력 JSON:
{
  "labels": [
    {"index": 1, "label": ""}
  ]
}
